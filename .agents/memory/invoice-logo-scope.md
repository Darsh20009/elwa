---
name: Invoice logo scope
description: Where the supplied Elwa logo should and should not be applied.
---

Keep the supplied Elwa logo on the default invoice and receipt templates. The national-campaign template uses the supplied campaign artwork full-width instead of the regular logo. Do not replace unrelated customer-site, staff, or app logos.

**Why:** the user wants the existing invoice to remain unchanged and the campaign image to be an optional template, not a general rebrand.

**How to apply:** Keep the logo in the default template; use the campaign artwork only when that template is selected, and leave non-invoice logo usage unchanged.
